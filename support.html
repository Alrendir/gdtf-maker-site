Questions fréquentes

Où trouver une clé API Anthropic ? Sur console.anthropic.com → API Keys. Elle n’est nécessaire que pour l’import automatique depuis un manuel (version Pro).

J’ai acheté Pro sur un autre appareil. Ouvrez la fenêtre Pro puis touchez « Restaurer mes achats ».

Où est mon fichier .gdtf ? L’export ouvre la feuille de partage : choisissez « Enregistrer dans Fichiers », AirDrop ou Mail.

FAQ

Where do I get an Anthropic API key? At console.anthropic.com → API Keys. It is only needed for automatic import from a manual (Pro).

I bought Pro on another device. Open the Pro sheet and tap “Restore purchases”.

Where is my .gdtf file? Export opens the share sheet: choose “Save to Files”, AirDrop or Mail.
